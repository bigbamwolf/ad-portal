PABAON order alerts

Makes this phone ring with the PABAON voice on every new website order, even when locked. For the A&D owners only. Android phones.

Turn on order alerts Get the latest A&D Portal app (version 1.0.2)
  1. Tap Turn on order alerts. If the app has not been updated yet, the download starts instead. Install it, then come back and tap again.
  2. Allow notifications.
  3. When asked about battery, tap Allow so alerts are never late.
  4. Tap Test the sound. You should hear the PABAON voice.
